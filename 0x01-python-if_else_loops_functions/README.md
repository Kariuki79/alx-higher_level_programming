# 0x01. Python - if/else, loops, functions

## Description
This project focuses on fundamental Python syntax and control flow structures, including conditional statements (`if`, `elif`, `else`), looping constructs (`for`, `while`), loop control mechanisms (`break`, `continue`, `pass`, `else`), the `range()` function, string formatting, custom function definitions, and variable scopes.

## Requirements
* Operating System: Ubuntu 20.04 LTS
* Python Version: Python 3.8.5
* Style Guide: `pycodestyle` (version 2.8.*)
* All files are executable and end with a newline.
* The first line of all Python scripts is `#!/usr/bin/python3`.
