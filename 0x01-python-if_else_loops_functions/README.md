# 0x01. Python - if/else, loops, functions

## Description
This project focuses on fundamental Python syntax and control flow structures, including conditional statements (`if`, `elif`, `else`), looping constructs (`for`, `while`), loop control mechanisms (`break`, `continue`, `pass`, `else`), the `range()` function, string formatting, and variable scopes.

## Requirements
* Operating System: Ubuntu 20.04 LTS
* Python Version: Python 3.8.5
* Style Guide: `pycodestyle` (version 2.8.*)
* All files are executable and end with a newline.
* The first line of all Python scripts is `#!/usr/bin/python3`.

## File Index
| File | Description |
|---|---|
| `0-positive_or_negative.py` | Determines whether a randomly generated integer is positive, zero, or negative |
| `1-last_digit.py` | Computes and displays the last digit of a random signed integer |
| `2-print_alphabet.py` | Prints the ASCII lowercase alphabet in ascending order without a trailing newline |
| `3-print_alphabt.py` | Prints the ASCII lowercase alphabet excluding the letters 'e' and 'q' |
