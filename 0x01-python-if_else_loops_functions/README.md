# 0x01. Python - if/else, loops, functions

## Description
This directory covers fundamental Python concepts including conditional branching (`if`, `elif`, `else`), loops (`for`, `while`), loop control mechanisms (`break`, `continue`, `pass`, loop `else`), the `range()` function, defining and invoking functions, and variable scope rules.

## Requirements
* Operating System: Ubuntu 20.04 LTS
* Python Version: Python 3.8.5
* Style Guide: `pycodestyle` (version 2.8.*)
* All files must be executable and end with a new line.
* The first line of all Python scripts must be `#!/usr/bin/python3`.
