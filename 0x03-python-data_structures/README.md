# 0x03. Python - Data Structures: Lists, Tuples

## Description
This project covers Python list operations, indexing, slicing, mutability, list comprehensions, tuples, tuple packing and unpacking, and sequence handling.

## Requirements
* Operating System: Ubuntu 20.04 LTS
* Python Version: Python 3.8.5
* Style Guide: `pycodestyle` (version 2.8.*)
* All files are executable and end with a newline.
* The first line of all Python scripts is `#!/usr/bin/python3`.

## File Index
| File | Description |
|---|---|
| `0-print_list_integer.py` | Prints all integers of a list using `str.format()` |
| `1-element_at.py` | Retrieves an element from a list at a given index safely |
| `2-replace_in_list.py` | Replaces an element of a list at a specific position in place |
| `3-print_reversed_list_integer.py` | Prints all integers of a list in reverse order |
| `4-new_in_list.py` | Replaces an element in a list copy without modifying the original list |
| `5-no_c.py` | Removes all occurrences of `c` and `C` from a string |
| `README.md` | Project documentation and file index |
