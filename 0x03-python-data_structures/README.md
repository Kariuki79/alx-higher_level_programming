# 0x03. Python - Data Structures: Lists, Tuples

## Description
This project covers Python list operations, indexing, slicing, mutability, list comprehensions, tuples, tuple packing and unpacking, and sequence handling.

## Requirements
* Operating System: Ubuntu 20.04 LTS
* Python Version: Python 3.8.5
* Style Guide: `pycodestyle` (version 2.8.*)
* All files are executable and end with a newline.
* The first line of all Python scripts is `#!/usr/bin/python3`.
